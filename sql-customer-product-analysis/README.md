# SQL Customer & Product Analysis 🗄️

## 📌 Overview
Real-world SQL data analysis focusing on customer behaviour 
and product performance using sales data.
Built using MySQL Workbench as a portfolio project.

## 🛠️ Tools
- MySQL Workbench
- GitHub

## 📂 Scripts
| Script | Description |
|--------|-------------|
| 01_AdvanceAnalysis | Advanced SQL analysis techniques |
| 02_DataSegmentation | Customer & product segmentation |
| 03_CustomerReport | Customer behaviour & insights |
| 04_ProductReport | Product performance & insights |

## ⚠️ Key Concepts Covered
| Concept | Description |
|---------|-------------|
| Customer Segmentation | VIP, Regular, New customers |
| Recency & Lifespan | Last order, buying duration |
| Product Analysis | Lifespan, avg selling price |
| Time Analysis | Trends, recency, frequency |
| Reporting | Aggregated business insights |

## ⚙️ MySQL Notes
| SSMS Syntax | MySQL Equivalent |
|-------------|-----------------|
| `GETDATE()` | `CURDATE()` |
| `DATEDIFF(MONTH,...)` | `TIMESTAMPDIFF(MONTH,...)` |
| `TOP N` | `LIMIT N` |
| `ISNULL()` | `IFNULL()` |
